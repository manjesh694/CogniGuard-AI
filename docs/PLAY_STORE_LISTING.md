# CogniGuard AI — Google Play Store Launch Kit (Android TWA)

Package the live CogniGuard Mobile Guardian PWA (`https://manjesh694.github.io/CogniGuard-AI/mobile_app.html`) as a signed Android App Bundle (`.aab`) via Trusted Web Activity (TWA) for Google Play Store.

---

## 1. Prerequisites
- Google Play Console Developer Account (`$25` one-time fee)
- Node.js 18+ and JDK 17+ installed locally

## 2. Generate Signed `.aab` via Bubblewrap
```bash
npm install -g @bubblewrap/cli
mkdir cogniguard-android && cd cogniguard-android
bubblewrap init --manifest https://manjesh694.github.io/CogniGuard-AI/manifest.webmanifest
bubblewrap build
```
Output bundle for upload: `app-release-bundle.aab`

> To hide the Chrome address bar inside the Play Store app, copy the SHA-256 fingerprint generated by Bubblewrap into `docs/.well-known/assetlinks.json` and push to `main`.

---

## 4. Play Console Data Safety Form
- **Data collected:** None by default (all SMS/URL inspection runs client-side unless the user explicitly connects their own self-hosted CogniGuard API Bridge).
- **Data shared with third parties:** No.
- **Security practices:** HTTPS in transit when connected to a cloud API bridge; no background tracking SDKs.
